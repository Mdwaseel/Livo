{% comment %} An asset is either a stored file or a link to one held on Drive (anything over the upload ceiling). `a.url` resolves to whichever it is; `a.is_link` picks the chain icon and the "lives elsewhere" wording. {% endcomment %} {% comment %} The thumbnail and the title below it are the same link to the same file. For a mouse that redundancy is a bigger target; for a keyboard it is two stops per asset and, in the icon cases, the first one announces as an unnamed link. So the thumbnail is marked decorative — clickable, out of the tab order — and the titled link underneath is the single accessible affordance. `tabindex="-1"` is what makes `aria-hidden` legitimate here: hiding a focusable element would otherwise strand focus on something screen readers cannot announce. {% endcomment %}
