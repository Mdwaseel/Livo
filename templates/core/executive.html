{% extends "base.html" %} {% load static %} {% comment %} The Executive Dashboard — what `/` renders for anyone with `analytics.view`. Reading order is the design: headline tiles, the operational strip, the AI brief with what to DO about it, then the evidence (charts), then what is wrong (alerts), then the people and the detail. Somebody who reads only the top third has still had the question answered. Everything here is a real figure from a real row. Where this install has no data for something an executive dashboard normally carries — tickets, SLA, AMC renewals, stock, CSAT, engagement surveys — there is no tile and no placeholder, because a plausible-looking zero is the number that gets repeated in a meeting. The footer says so out loud rather than leaving a reader to wonder whether the figure is hidden, broken, or genuinely zero. Money is gated twice: `analytics.view` opens the page, `business.view` decides whether revenue exists on it at all. `business.view`, not `finance.view` — holding the finance key means you can open an invoice, which is not the same as being shown the agency's cash position. Tiles, charts and columns are ABSENT without it, not blanked — see core/views_executive.py. {% endcomment %} {% block crumb %}Dashboard{% endblock %} {% block title %}Dashboard · Livo OS{% endblock %} {% block content %}
