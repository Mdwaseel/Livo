A chart that drills through on click is a MOUSE affordance. Every one of them on this dashboard is paired with a table carrying the same links, which is the keyboard and screen-reader path to the same place — if you add a clickable chart without one, the destination is unreachable for anyone not using a pointer. WHEN THERE IS NOTHING TO PLOT the canvas is not rendered at all. Chart.js draws an empty grid for an all-zero bar chart and draws literally nothing for an all-zero doughnut, so a fresh install showed a wall of blank rectangles with titles over them — which reads as broken software rather than as an empty database. A sentence saying which figure is missing is both honest and more useful, and it tells you what to go and do about it. {% endcomment %}
